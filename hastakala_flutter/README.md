# Hastakala Flutter UI

A polished SIH26090 frontend prototype.

## Run
1. Install Flutter.
2. Open this folder in VS Code or Android Studio.
3. Run:
   flutter pub get
   flutter run

## Included flow
Splash → Language → Login → Dashboard → Add Product → Voice AI →
AI Processing → Catalog Review → Smart Pricing → Publish.

Also includes Products, AI Assistant, and Profile.
